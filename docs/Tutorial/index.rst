#######################
METplus 13.0.0 Tutorial
#######################

The METplus Tutorial provides hands-on guidance for using the METplus
verification framework after it has been successfully installed. The
tutorial is designed to help users of all experience levels work with
METplus, from running basic use cases to exploring advanced verification
techniques. Whether evaluating model forecasts or analyzing ensemble
output, the tutorial provides step-by-step instructions and practical
examples to support workflows.

The tutorial focuses on practical applications of METplus, including
grid-to-grid and grid-to-point comparisons, ensemble verification, and the
use of custom configurations to tailor workflows to user's specific needs.

The METplus v13.0.0 practical consists of 11 sessions. The first six sessions
contain instructions for running individual MET tools directly on the command
line, followed by instructions for running the same tools as part of a METplus
use case. The remaining sessions dive into special applications of METplus and
the Analysis tools available in the METplus suite.
