#################
METplus Tutorials
#################

The METplus Tutorials provide hands-on guidance for using the METplus
verification framework after it has been successfully installed. These
tutorials are designed to help users of all experience levels work with
METplus, from running basic use cases to exploring advanced verification
techniques. Whether evaluating model forecasts or analyzing ensemble
output, the tutorials provide step-by-step instructions and practical
examples to support workflows.

Each tutorial focuses on practical applications of METplus, including
grid-to-grid and grid-to-point comparisons, ensemble verification, and the
use of custom configurations to tailor workflows to user's specific needs.

Select the appropriate version to get started.
