*********************
METplus v5.0 Tutorial
*********************

The METplus v5.0.0 practical consists of 11 sessions. The first six sessions
contain instructions for running individual MET tools directly on the command
line, followed by instructions for running the same tools as part of a METplus
use case. The remaining sessions dive into special applications of METplus and
the Analysis tools available in the METplus suite.
